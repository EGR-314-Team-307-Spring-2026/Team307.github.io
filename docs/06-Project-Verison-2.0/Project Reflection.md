## Overview
* If Team 307 were to create a second version of this project, the biggest improvement to make would be on the Temperature sensing subsystem. In the sequence diagram, it is show that the Temperature sensing subsystem is labeled "Not Applicable" this is due to the subsystem not being functional by the time the innovation showcase occurred, here are some improvements that can expect the Temperature sensing subsystem to be functional in this second version of the project. A major improvement would be the component footprint sizing, meaning that I need to make sure that my components are not extremely small and to try to get the bigger sized component if applicable. Due to having such smaller sized components such as a PIC18(LF)47K42 Microcontroller, and a TMP1075DGK temperature sensor for example, this had made soldering more difficult and was extremely time consuming. With having the bigger footprint sized components, it overall makes the surface mount soldering simpler saving more time in the long run.
