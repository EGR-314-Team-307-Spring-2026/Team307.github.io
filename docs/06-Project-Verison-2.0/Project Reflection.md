## Overview
* If Team 307 were to create a second version of this project, the biggest improvement to make would be on the Temperature sensing subsystem. In the sequence diagram, it is showing that the Temperature sensing subsystem is labeled "Not Applicable", this is due to the subsystem not being functional by the time the innovation showcase occurred, here are some improvements that can expect the Temperature sensing subsystem to be functional in this second version of the project. A major improvement would be the component footprint sizing, meaning that it needs to be verified that the components are not extremely small and to try to get the bigger sized component if applicable. Due to having such smaller sized components such as a PIC18(LF)47K42 Microcontroller, and a TMP1075DGK temperature sensor for example, this had made soldering more difficult and was extremely time consuming. With having the bigger footprint sized components, it overall makes the surface mount soldering simpler saving more time in the long run. Another major improvement would be by adding test points on the PGD and PGC pins for the MPLab Snap debugger to ensure a clean MCLR pull-up. This is benificial because while manufacturing the Temperature sensing subsystem and attempting to flash code into the subsystem from MPLab, it would give a "PGC error" meaning that it could be a issue with the MCLR pin connection from the MPLab Snap debugger to the  PIC18(LF)47K42 Microcontroller as well as making sure that the configuration bits were set, which they were. With that, MPLab does not always explicitly state what the exact issue So by having those test points installed instead of constant trial and error, we would be able to narrow down the debugging issue sooner allowing more time to complete the subsystem. With these improvements this can allow the Temperature sensing subsystem to get to the point of attempting to run a protocol design in this second version of the project instead of the subsystem being "Not Applicable."
